Política de Privacidade

Publicador G-TECH SYSTEM · atualizada em 8 de outubro de 2026

1. Quem somos

O Publicador G-TECH SYSTEM é uma ferramenta interna da G-TECH SYSTEM usada exclusivamente para enviar e agendar vídeos no canal oficial da própria empresa no YouTube. Contato: gtech.instrumentacao@gmail.com.

2. Dados acessados

Com a autorização da conta Google da empresa, a ferramenta usa os Serviços de API do YouTube apenas para: enviar vídeos (videos.insert), definir a miniatura (thumbnails.set) e agendar a publicação. Ela não lê e-mails, contatos, arquivos nem dados de outros usuários ou canais.

3. Armazenamento

O único dado guardado é o token de acesso OAuth da conta da empresa, mantido no servidor da própria empresa, com acesso restrito. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

4. Serviços de API do YouTube

Esta ferramenta usa os Serviços de API do YouTube. Ao usá-la, você concorda com os Termos de Serviço do YouTube. Veja também a Política de Privacidade do Google.

5. Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, o token deixa de funcionar; para apagá-lo do servidor, escreva para o contato acima.

Summary (English)

Publicador G-TECH SYSTEM is an internal tool used only by G-TECH SYSTEM to upload and schedule videos to its own YouTube channel through the YouTube API Services (videos.insert, thumbnails.set). It stores only the company's OAuth token on the company's own server, accesses no other user data, and shares nothing with third parties. By using it you agree to the YouTube Terms of Service; see the Google Privacy Policy. Access can be revoked at myaccount.google.com/permissions.
